# Chasm: The Rift — J2ME Edition (Nokia S60 & Sony Ericsson)

Порт культового DOS 3D-шутера **Chasm: The Rift** (Action Forms, 1997) на платформу **J2ME (CLDC 1.1 / MIDP 2.0)** для кнопочных телефонов **Nokia Series 60 (S60)** и **Sony Ericsson (JP-7 / JP-8)**.

---

## Сборка и готовые файлы

- **`ChasmTheRift.jar`** (~290 КБ) — преверифицированный (`StackMap`, `major version 45 / Java 1.1`) J2ME-пакет, готовый к запуску на реальных телефонах Nokia S60, Sony Ericsson и в эмуляторах (KEmulator, FreeJ2ME, J2ME Loader, MicroEmulator).
- **`ChasmTheRift.jad`** — дескриптор MIDlet-пакета.
- **`tex.zip`** и **`PC Computer - Chasm The Rift - Sound Effects.zip`** — переименованные обратно из `.jpg` в `.zip` архивы оригинальных текстур и звуковых эффектов.
- **`tools/build_assets.py`** — конвертер ресурсов (текстур, `.CAR`/`.3O`/`.ANI` 3D-моделей с запечёнными Flat Shading и Vertex Colors / Vertex Painting, многоуровневых карт `MAP.01`/`05`/`06` со ступенями и стенами разной высоты, 8 кГц WAV-звуков и многоканальной MIDI-музыки).
- **`build.sh`** — полный скрипт сборки через инструментарий [`LLM-J2ME-SUITE`](https://github.com/klaxons1/LLM-J2ME-SUITE/) (`javac -source 1.3 -target 1.1` + `proguard.jar -microedition`).

## Техническая архитектура и оптимизации под J2ME (Nokia S60 / Sony Ericsson)

### 1. Учёт аппаратных особенностей Nokia S60 и Sony Ericsson
- **Целочисленная математика с фиксированной точкой (`16.16` и `8.8` Fixed-Point):** полное отсутствие `float`/`double` в игровом цикле, рейкастере и 3D-растеризаторе. Тригонометрия (`SIN[1024]`, `COS[1024]`) предвычислена по формуле Бхаскары I.
- **Zero-GC в игровом цикле:** все буферы кадра (`screenBuf`, `zBuffer`), массивы трансформации вершин (`viewX`, `viewY`, `viewZ`, `scrX`, `scrY`), списки сортировки треугольников и пулы сущностей (монстров, предметов, 3D-снарядов, отстреленных конечностей) выделяются один раз при старте. Во время рендеринга и логики не создаётся ни одного объекта (`new`), что исключает фризы сборщика мусора (`GC`) на Symbian S60.
- **Прямой вывод кадра (`Graphics.drawRGB`):** весь 3D-кадр собирается в едином `int[] screenBuf` с поддержкой адаптивных разрешений (`128×160`, `176×208`, `176×220`, `240×320`, `320×240`).
- **Аудио-подсистема (`JSR-135 MMAPI`):** фоновая музыка в формате **General MIDI (`.mid`)** и предзагруженные в `byte[]` звуковые эффекты (`8000 Hz, 8-bit Mono PCM .wav`) с безопасным арбитражем `Player` для телефонов Nokia S60 и Sony Ericsson + тактильная виброотдача (`Display.vibrate`).

### 2. Рейкастинг-движок со стенами разной высоты и ступенями (`RaycasterEngine.java`)
- **Многоуровневая секторная сетка `64×64`:** каждая ячейка хранит независимые высоты пола (`floorH`), потолка (`ceilH`) и стены (`wallH`).
- **Стены разной высоты (`wallH = 48..160`):** при попадании луча в низкую или среднюю стену (`wallH < curCeilH`) движок отрисовывает видимую часть стены, сдвигает нижнюю границу отсечения столбца (`yBot = wallTopY - 1`) и **продолжает трассировку луча дальше**, позволяя видеть более высокие здания, пирамиды и скайбокс (`SKY.CEL` / `SKY2.CEL`) позади низкой стены.
- **Ступени и лестницы (`floorH = 0..84`):** при переходе луча между ячейками с разной высотой пола (`nextFloorH > curFloorH`) отрисовывается вертикальный торец ступени (`stepTex`) с текстурным маппингом по мировой координате `Z`, обновляется `yBot`, а при движении игрока камера плавно поднимается и спускается по ступеням.
- **Транспонированный атлас текстур и предвычисленный свет:** текстуры стен хранятся по столбцам (`u * 64 + v`), а освещение (`16` уровней яркости для `256` цветов `CHASM2.PAL`) выбирается за одно обращение `lightPal[shade][texel]` без побитовых сдвигов на каждый пиксель.

### 3. Полигональные 3D-враги и оружие с Flat Shading и Vertex Colors / Vertex Painting (`Model3D.java`, `Renderer3D.java`)
- Сконвертированы 36 оригинальных полигональных 3D-моделей из `CSM.BIN` (`.CAR` враги: *Mong*, *WingMan*, *Spider*, *Turret*, *Faust*, *DeadMan*, *Punisher*, *Joker*, *Skeleton*, *Lion*, *Viking/Overlord*; `.3O` оружие в руках, предметы, декор и снаряды).
- Поддерживаются **3 переключаемых на лету режима рендеринга 3D-полигонов** (клавиша `*` в игре или в меню):
  1. **`FLAT + VERTEX COLOR` (Гибридный):** сочетает динамическое освещение плоских граней по 3D-нормали (`N · L`) с запечёнными цветами вершин (**Vertex Painting** + вертикальный Ambient Occlusion).
  2. **`FLAT SHADING` (Одноцветные полигоны):** классическая заливка каждого треугольника единым динамически освещённым цветом.
  3. **`VERTEX PAINTING` (Gouraud Scanline Interpolation):** плавная построчная интерполяция `(R, G, B)` цветов вершин по площади каждого полигона в фиксированной точке `8.8`.
- **Фирменное расчленение врагов (Limb Dismemberment):** полигоны `.CAR` моделей разбиты по группам (`group_id`: левая рука, правая рука с оружием, голова, кровавые культи). При нанесении тяжёлого урона у врага отлетает рука (`GIB1.3O`), открывается группа полигонов культи, а враг теряет способность вести дальний огонь.

## Управление (Nokia S60 & Sony Ericsson)

| Клавиша | Действие |
|---|---|
| **`2` / `UP`** | Идти вперёд (с автоматическим подъёмом по ступеням) |
| **`8` / `DOWN`** | Идти назад |
| **`4` / `LEFT`** | Поворот влево |
| **`6` / `RIGHT`** | Поворот вправо |
| **`1` / `3`** | Стрейф влево / вправо |
| **`5` / `FIRE`** | Огонь из текущего 3D-оружия / Открыть дверь вплотную |
| **`7`** | Прыжок |
| **`9`** | Смена оружия (6 видов оружия Chasm) |
| **`#` / Правая софт-клавиша** | Открыть дверь / Нажать переключатель |
| **`*`** | Переключение режима 3D-шейдинга (`FLAT+VERTEX` / `FLAT` / `VERTEX`) |
| **`0`** | Включить / выключить автокарту (с цветовой индикацией ступеней и стен) |
| **Левая софт-клавиша** | Меню паузы |
